**Version checked October 27, 2026:** Midjourney’s official documentation identifies **V8.2** as the current model. Every prompt explicitly selects `--v 8.2`. The shared settings use supported `--ar 2:3`, `--raw`, and `--s 125` syntax. Paste a code block into the web Imagine bar or Discord’s `/imagine` prompt field. [Official version and compatibility](https://docs.midjourney.com/hc/en-us/articles/32199405667853-Version), [parameter syntax](https://docs.midjourney.com/hc/en-us/articles/32859204029709-Parameter-List), [Raw](https://docs.midjourney.com/hc/en-us/articles/32634113811853-Raw), [Stylize](https://docs.midjourney.com/hc/en-us/articles/32196176868109-Stylize).

**Shared visual direction:** painterly, grounded magitech space fantasy; readable silhouettes, restrained colors, expressive faces, brushed-metal and cloth textures, cool ambient light with warm practical accents. This direction is an artistic choice. Use the same account personalization settings across the set. No reference images are required.

**Canon and interpretation:** each entry separates established details from optional visual choices. Where the logs leave appearance open, the proposed face, age, hairstyle, or costume is a provisional design, not new campaign canon. Portrait staging does not assert that the exact pose happened in play.
